# Harrison Barrow, Attorney at Law, P.C. — Website

A fast, static, SEO- and AI-optimized site for a Cape Cod criminal-defense and civil-litigation
practice. Premium "midnight slate & gold" design. Hosts on GitHub Pages (or any static host) with
no build server required.

- **19 pages:** Home, Harrison Barrow (bio), Criminal Defense hub + 8 practice areas, Civil
  Litigation, Results, Reviews, Contact, Thank-You, Privacy, 404, plus an `/about/` → `/harrison-barrow/` redirect.
- **Generated by `build.py`** from `site_data.py`. Edit content there and re-run `python3 build.py`.
- **Canonical domain:** `https://harrisonbarrow.com` (set in `site_data.py`).

## What I improved over the previous `website` version
- **No-JavaScript / reduced-motion fallback.** Previously every section started invisible
  (`opacity:0`) and only appeared once scroll-animation JS ran. Now all content is visible by
  default; the animation is pure enhancement, and the sliders fall back to wrapped grids. Better for
  accessibility, for crawlers, and if a script ever fails.
- **Removed the "Avvo 10.0 / Superb" rating claims** everywhere (hero, bio, criminal-defense page,
  schema, llms.txt), consistent with your edit to `site_data.py`. Massachusetts Rule of Professional
  Conduct 7.1 is strict on rating/comparative claims. The Avvo *profile link* on the Reviews page
  remains (legitimate).
- **Brand mark added.** The gold sailboat logo now sits in the header and footer beside the wordmark.
- **Premium line icons** replace the emoji practice-area icons (gold, consistent stroke weight).
- **Dedicated social-share image** (`/assets/img/og-image.jpg`, dark + gold, criminal & civil) instead
  of reusing the hero photo.
- **Forms land on the Thank-You page** after submit (Formspree `_next` redirect).
- **Accessibility:** skip-to-content link and visible keyboard focus styles.

## 1. Deploy to GitHub Pages
1. Create a repo and push the contents of this folder to the `main` branch (the `.gitignore` excludes
   `__pycache__`). The `.py` files are safe to include but aren't needed for hosting.
2. **Settings → Pages →** Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. The `CNAME` file already contains `harrisonbarrow.com`. Tick **Enforce HTTPS** once the cert issues.
4. `.nojekyll` is included so GitHub serves the files as-is.

## 2. DNS for harrisonbarrow.com
At your DNS host, create **four A records** for the apex:
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```
Optional **AAAA (IPv6):** `2606:50c0:8000::153`, `…8001::153`, `…8002::153`, `…8003::153`.
**`www`** → CNAME to `YOUR-GITHUB-USERNAME.github.io`.
(Values per GitHub's docs, June 2026 — verify they're current before relying on them.)

## 3. Redirect htb3.com → harrisonbarrow.com
Use your registrar's domain-forwarding (301) or a Cloudflare bulk redirect:
`htb3.com/*` → `https://harrisonbarrow.com/$1`. A 301 passes the most SEO value to the new domain.

## 4. Contact forms (Formspree)
All three forms post to **`https://formspree.io/f/xjgznjbe`**. Confirm that is your Formspree form
(log in at formspree.io). Submissions email you and then redirect to `/thank-you/`. To change the
destination, edit the `action=` URL in `build.py` and re-run, or directly in the HTML.

## 5. Editing content
Everything lives in **`site_data.py`** (firm info, practice areas, results, reviews) and the page
builders in **`build.py`**. After any change:
```bash
python3 build.py
```
This regenerates all pages, the sitemap, robots.txt, and llms.txt with consistent headers, footers,
and structured data. (Re-creating the gold mark / OG image needs Python + Pillow; text/HTML edits
need nothing.)

## What's built in for SEO + AI
- **JSON-LD** on every page: `LegalService` + `Attorney` (Person) with NAP, `Service` per practice
  area, `FAQPage`, `BreadcrumbList`, `WebPage`, plus `Review`s.
- **robots.txt** explicitly allows GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot,
  Google-Extended, PerplexityBot, Applebot-Extended, and more.
- **llms.txt** clean site map for language models; **sitemap.xml**; per-page meta, Open Graph,
  Twitter cards; canonical URLs; mobile-first; fast (no framework).
